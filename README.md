# Coffee Shop Sales Analysis | Power BI

## Project Overview
This project analyzes 149,000 coffee shop orders to uncover sales trends, product-category performance, location-level revenue, and peak purchasing periods.

## Business Problems
- Which products and categories contribute most to sales?
- Which store locations perform best?
- When do customers purchase most frequently?
- What insights can support better inventory and sales decisions?
